# Pixel-art video: сюжет → код → видео

Ролик делается кодом: каждый кадр рисуется на маленьком холсте (обычно 320×180) в
фиксированной палитре, увеличивается целым коэффициентом без сглаживания и
кодируется в MP4 вместе с синтезированной 8-битной музыкой. Всё детерминировано —
можно смотреть любые кадры до рендера и править точечно.

Файлы скилла (пути — относительно папки, где лежит этот SKILL.md; в Claude Code
обычно это `~/.claude/skills/pixel-art-video/`):
- `scripts/pixelvid.py` — движок (импортируй, не переписывай).
- `examples/template.py` — заготовка фильма, копируй её для нового ролика.
- `examples/lighthouse.py` — полный пример 27-секундного фильма «Маяк»
  (шторм, свет, персонаж, вода, закат, музыка, sfx). Смотри, как решены типовые задачи.
- `examples/star_cat.py` — второй пример, «Звезда» (23 с, палитра sweetie16): кот,
  сжатие/растяжение в прыжках, анимированный хвост, слои города, уютный lofi-саунд.
- `examples/super_pixel.py` — платформер в духе NES (36 с): прокрутка камеры, прыжки
  по дугам, блоки, враги, неуязвимость, HUD со счётом, флаг, салют, игровая музыка.
- `references/story.md` — **как придумывать сюжет** (форматы, биты, генератор идей,
  рассказ без слов). Читай при любой задаче, где нужно придумать или доработать историю.
- `references/craft.md` — правила пиксель-арта для видео и **чек-лист ревью**.
- `references/api.md` — шпаргалка по всем функциям движка и нотации музыки.

## Подготовка (один раз на машине)

```bash
python -c "import PIL, numpy, imageio_ffmpeg; print('ok')"
```
Если чего-то нет: `pip install pillow numpy imageio imageio-ffmpeg scipy`
(`imageio-ffmpeg` приносит свой ffmpeg — отдельная установка не нужна; scipy необязателен).

## Процесс

### 1. Сюжет
Прочитай `references/story.md`. Определи формат (луп / микро-история / короткий фильм,
16:9 или 9:16) и длительность. Если пользователь дал только тему или ничего — придумай
сам: логлайн, главный образ, цветовой сценарий, биты. Если запрос расплывчатый и
пользователь явно хочет выбирать — предложи 3 коротких варианта; иначе не тормози,
выбери лучший и покажи его вместе с результатом.

Запиши план как таблицу сцен (длительность, что видно, что движется, звук). Держи
историю простой: 1–2 персонажа, события показаны светом, погодой, предметами и
простыми действиями — сложную мимику и драки пиксели не вытянут.

### 2. Проект
Создай папку ролика (по умолчанию `~/pixel-films/<slug>/`, если пользователь не указал
другую), скопируй туда `examples/template.py` как `film.py`. Шаблон ищет движок в
`~/.claude/skills/pixel-art-video/scripts` или в переменной окружения `PIXELVID_DIR`;
если скилл лежит в другом месте — поправь строку `sys.path.insert` на реальный путь
к папке `scripts/` этого скилла. Вверху файла — докстринг
с логлайном и битами: это документация и память для последующих правок.

### 3. Код сцен
Каждая сцена — функция `(c, x)`, рисующая кадр по времени `x.t`. Порядок рисования:
небо → дальние слои → средние → земля → персонажи/предметы → погода/частицы →
свет (`night`, `glow`) → текст. Используй готовое из движка (декорации, частицы,
`humanoid`, `keys`/`seg` для таймингов). Свои спрайты — ASCII-сеткой через
`Sprite.from_ascii`. Подробности API — `references/api.md`; приёмы — `lighthouse.py`.

Почему именно так: чистая функция времени позволяет рендерить стоп-кадры в любой
момент без прогона всего фильма, а готовые хелперы уже решают пиксельные тонкости
(целые координаты, дизеринг вместо прозрачности, палитровое затемнение).

### 4. Ревью по стоп-кадрам — обязательно, до рендера
```bash
python film.py preview <out_dir>          # 12 кадров равномерно
python film.py stills 3.5,7.2,9 <out_dir> # конкретные моменты
```
Открой PNG инструментом Read и пройди чек-лист из `references/craft.md`
(читаемость главного объекта, изменение в каждой сцене, нет мёртвых кадров, текст не
обрезан, нет грязного дизеринга, кульминация — самый яркий кадр). Исправь и повтори.
Обычно нужно 2–3 итерации. Самые частые проблемы первой версии (обе встречались
в тестах): герой/главный объект слишком мелкий (увеличь через `.scaled(2..3)`) и
передний план сливается с фоном (задний слой светлее, передний темнее, у переднего
края — светлая кромка).

### 5. Музыка и звук
В `soundtrack()` собери `Song`: мелодия (square), бас (triangle), арпеджио-аккорды,
барабаны по жанру, эмбиент (дождь/ветер/море) и sfx, привязанные к
`mv.scene_start(...)`. Таблица «жанр → палитра → музыка» — в story.md, нотация — в api.md.
Звук обязателен: без него пиксельный ролик ощущается пустым.

### 6. Рендер
```bash
python film.py render <out_dir>   # MP4 H.264 + AAC
python film.py gif <out_dir>      # если нужен GIF (без звука)
```
27 с 720p рендерится ~15 с. Для 1080p: `scale=6`. Для вертикали: `Movie(180, 320, scale=6)`.

### 7. Сдача
Покажи пользователю: название, логлайн, таблицу сцен (кратко), путь к MP4 и превью.
Если доступен `SendUserFile` — отправь MP4 и contact sheet. Предложи, что можно
улучшить (длиннее, вертикаль, другой финал, другая палитра, свои спрайты).

## Главные правила стиля (коротко)
- Только цвета палитры; никакого сглаживания и нецелого масштаба.
- Полупрозрачность, свет и градиенты — через дизеринг.
- Спрайты анимируются с 6–12 fps, видео — 24 fps.
- В кадре всегда что-то живёт (дождь, звёзды, вода, мерцание).
- Крупные планы — отдельной сценой со `sprite.scaled(2..3)`, а не зумом.
- Каждая сцена что-то меняет; финал отличается от начала цветом.

## Если что-то сломалось
- `ModuleNotFoundError` → установи пакеты из «Подготовки».
- Кириллица в консоли Windows может падать при `print` — не печатай русский текст
  из скриптов (в кадрах он рисуется пиксельным шрифтом без проблем).
- Неизвестный символ в тексте рисуется как `?` — шрифт: заглавные латиница и
  кириллица, цифры, основная пунктуация (строчные автоматически → заглавные).
- Функции нет в движке — напиши её в `film.py` поверх `Canvas` (numpy-массив
  доступен через `c.arr()` / `c.put(a)`); если она полезна многим фильмам — добавь в
  `pixelvid.py` и в `references/api.md`.
